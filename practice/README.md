# ✏️ 题目练习

一个独立的做题练习页，地址：`practice/index.html`（入口页「题目练习」图标）。

## 功能

- **进入即做题**：打开页面自动开始出题，无需点开始按钮。
- **连续练习**：答对后短暂停留（约 1.2 秒）自动随机出下一题；答错会提示并抖动，可反复重试同一题，直到答对。
- **随机题型**：十以内加法、十以内减法、奇数/偶数顺数填空三种题型随机出现，全部与游戏内共用同一套题库。
- **跳过不计数**：点「🔄 换一题」直接换一题，不计入统计。
- **即时统计**：做题时弹窗顶部实时显示「已做 / 答对 / 需再想 / 正确率」。
- **成绩单**：点「🏠 结束练习」关闭弹窗后展示本次成绩，并按正确率给出奖牌和鼓励语，可「再练一次」或「返回主页」，方便家长检验。

## 统计口径

每道新题**首次作答**计入 1 题；首次答对记「答对」，首次答错记「需再想」（之后重试答对不重复计数）。正确率 = 答对 ÷ 已做。

## 实现

本页不含题库逻辑，仅调用公共模块 [`../quiz.js`](../quiz.js) 的练习模式：

```js
GameQuiz.startPractice({
  speech: true,
  onScore: function (s) { /* s = {total, right, wrong, rate} */ },
  onExit: function () { /* 点击结束练习 */ }
});
```

题目生成、作答判定、统计、样式全部集中在 `quiz.js`，维护只需改那一处。新增题型见 `quiz.js` 的 `QUESTION_TYPES` 注册表。
