# 🎮 Game Box（游戏盒子）

> 一个专门收集各类小游戏的仓库，给家里的小朋友玩。

## 📖 关于本项目

这里集中存放各种适合小朋友玩的游戏，方便统一管理、分享和留存。仓库采用**「一个游戏一个文件夹」**的组织方式，后续每新增一款游戏，只需在 [`games/`](games/) 下新建对应目录即可。

## 📁 目录结构

```text
game-box/
├── games/          # 所有游戏都放在这里，每个游戏一个独立文件夹
│   └── README.md   # 游戏目录规范与添加说明
├── practice/       # 题目练习页：连续做题 + 成绩统计（家长检验用）
│   └── index.html
├── quiz.js         # 公共「定时做题 + 练习」模块——所有页面共用的题目源（单一维护点）
├── icons.js        # 公共手绘 SVG 图标库——水果/动物/场景/UI 装饰，统一果冻质感（单一维护点）
├── theme.css       # 公共视觉主题——统一背景/字体/按钮/胶囊/返回键/弹层（单一维护点）
├── save.js         # 公共进度存档模块——各游戏刷新后继续玩（单一维护点）
├── tools/          # 离线维护脚本（关卡生成 / 校验 / 浏览器端到端测试，非运行时依赖）
├── index.html      # 统一入口页（手机 App 图标式）
└── README.md       # 项目总说明
```

## 🧠 公共做题模块（quiz.js）

根目录的 [`quiz.js`](quiz.js) 提供两种模式，题目逻辑只维护这一处：

- **游戏内定时弹题**：所有游戏接入，游戏进行中每隔一段时间弹一道题，答对加分，让小朋友边玩边学。
- **独立练习模式**：[`practice/`](practice/) 练习页调用 `GameQuiz.startPractice()`，连续出题、答对自动下一题、带成绩统计，方便小朋友自己练习和家长检验。

- **单一维护点**：题目类型、弹题间隔、弹窗样式全部集中在这一个文件，改一处即对所有游戏生效。
- **目前题型**（游玩时随机出现）：十以内加法（点选）、十以内减法（点选）、奇数/偶数顺数填空（如 `1、3、_、7`、`2、4、6、_`，公差 2、都在 10 以内，自己输入数字）。
- **两种作答方式**：选择题给出 4 个选项点选；输入题（`input: true`）不给选项，由小朋友自己输入数字、点「确定」提交。
- **新增题型**：在 `quiz.js` 里写一个题目生成函数并加入 `QUESTION_TYPES` 数组即可，无需改任何游戏。
- **接入新游戏**：在页面引入 `<script src="../../quiz.js"></script>`，再调用 `GameQuiz.init({...})` 并按需提供 `isPlaying` / `onOpen` / `onClose` / `onReward` 回调，详见 `quiz.js` 顶部注释。

## 🎨 公共图标库（icons.js）

根目录的 [`icons.js`](icons.js) 提供全套统一风格的手绘 SVG 图标（果冻质感 / 2.5D 微立体，左上光源、渐变高光、统一描边，与消消乐同一套美术语言）：

- **水果**：苹果、橙子、柠檬、西瓜、葡萄、草莓、樱桃、桃、芒果、菠萝、猕猴桃、蓝莓
- **动物**：狗、猫、狐狸、熊猫、狮子、青蛙、兔子、熊；另有仓鼠、炸弹、星星、花
- **场景/特效**：小孩、终点旗、星光、爱心
- **UI 装饰**：主页、刷新、奖杯、时钟、目标、火焰、机器人、灯泡、播放、声音、火车、飞机、皇冠、棋子等约 50 个白色符号（`GameIcons.symbol(name)`）与彩色徽章（`GameIcons.badge(name)`）
- **三种用法**：DOM 彩色图标 `GameIcons.get("apple")`；纯白符号 `GameIcons.symbol("home")`（放进已有彩色底的按钮）；Canvas 用 `GameIcons.image("apple", cb)` 拿到 `<img>` 再 `drawImage`。
- **自动装饰**：页面引入 icons.js 后会自动把 `.home-btn` 换成统一 SVG 房子，把 `[data-icon="名字"]` 占位符和文本里的装饰 emoji 自动换成 SVG（公共题库 `gq-*` 弹窗除外，由 quiz.js 自身维护）。
- **单一维护点**：改图标只需改这个文件，所有游戏立即生效。

## 🎨 公共视觉主题（theme.css）

根目录的 [`theme.css`](theme.css) 统一了所有 2D 游戏的美术语言，与图标库同为果冻质感 / 2.5D 微立体风格：

- **统一变量**：奶油糖果背景渐变、深棕主文字、草莓粉主色、糖果橙强调色、统一圆角/柔和阴影/字体，全部走 CSS 变量，改一处全站生效。
- **统一组件**：`.home-btn` 返回键、`.pill` 胶囊、`.btn` 按钮（含 blue/green/yellow/purple/red 变体）、`.brand` 标题、`.overlay` 弹层、`.jelly-tile` 果冻数字块。
- **用法**：页面 `<head>` 里 `<link rel="stylesheet" href="../../theme.css">` 即可；页面自身样式可覆盖同名类做微调。
- 数字块、棋子、砖块、泡泡等游戏元素也按同一套质感（柔和渐变 + 内高光 + 底部实心阴影 + 统一描边）绘制。3D 飞行大冒险按原样保留，不套用本主题。

## 📱 移动端触摸适配

所有游戏都面向手机 / iPad 触摸操作：棋盘类游戏支持**滑动手势**，界面上不显示虚拟方向键（按钮功能与事件仍保留在代码中，仅隐藏显示）。小火车用左右滑动换轨、轻点鸣笛。

## 💾 进度存档（save.js）

根目录的 [`save.js`](save.js) 让各游戏把进度存到本机，刷新页面自动恢复，不必从头再来：`GameSave.save(key, data)` 保存、`GameSave.load(key, fallback)` 读取、`GameSave.clear(key)` 清档。棋盘 / 解谜类存完整局面，关卡制存当前关卡与分数，实时街机类存最高分 / 最高波次。存档带 `gb_save_v1_` 前缀并有异常保护，「重新开始」会清对应进度。详见 `games/README.md`。

## ➕ 如何添加一个游戏

1. 在 `games/` 下新建一个以游戏名命名的文件夹，例如 `games/tetris/`；
2. 把游戏相关文件（网页源码、安装包、素材等）放进该文件夹；
3. 在该文件夹内新建一个 `README.md`，写清楚游戏名称、玩法、适合年龄和运行方式；
4. 若是网页游戏，接入公共能力：在 `<head>` 引 `../../theme.css` 统一视觉，在脚本前引 `../../icons.js` 统一图标，引 `../../quiz.js` 调用 `GameQuiz.init(...)`，并引 `../../save.js` 用 `GameSave` 保存进度（见上文说明）；引入后返回键、装饰 emoji 会自动换成统一 SVG；
5. 在根目录 `index.html` 加一个图标入口，并在上方游戏清单补一行；
6. 提交并推送：

```bash
git add .
git commit -m "添加游戏: 游戏名"
git push origin main
```

更详细的规范见 [`games/README.md`](games/README.md)。
