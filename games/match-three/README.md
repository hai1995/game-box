# 🍬 消消乐

经典三消游戏，交换相邻水果，三个相同连成一线即可消除得分。

## 玩法

- 点击一个水果选中，再点击相邻的水果交换位置。
- 交换后若有三个及以上相同水果连成横线或竖线，就会消除并得分，上方水果下落、顶部补充新的。
- 一次消除引发连续多轮消除时会有「连击 xN」加成，连击越高得分越多。
- 45 步内累计达到 1200 分即过关（步数更充裕）；步数用完未达标则挑战失败。
- 「🔄 重新挑战」重开一局；若棋盘没有可消除的交换会自动洗牌。

## 美术风格

水果为手绘 SVG，全套统一为**果冻质感 / 2.5D 微立体**风格：

- **造型**：圆润饱满、略 Q 版，6 种水果剪影各不相同（草莓/橙子/柠檬/西瓜/葡萄/蓝莓），48px 下也能一眼区分。
- **色彩**：每种水果有明确主色，覆盖红橙黄绿紫蓝，高饱和但不刺眼。
- **质感**：统一左上光源，柔和渐变 + 细腻高光 + 短软阴影（CSS `drop-shadow`）；无写实纹理与强反光。
- **描边**：统一深色描边、圆角收尾，外轮廓干净。

> 维护提示：6 个水果 SVG 定义在脚本顶部的 `FRUIT_SVG` 数组，共用 `<defs>` 里的 6 个渐变 `g0`~`g5`；棋盘格子存的是数组索引（数字 0~5），不是 SVG 字符串。判空一律用 `!= null`，因为索引 `0` 也是有效水果，不能用 truthy 判断。

## 运行

打开 [index.html](index.html) 即可，或在入口页点击「消消乐」图标。纯前端，无需联网。已接入公共做题模块，游玩中会定时弹出题目。
