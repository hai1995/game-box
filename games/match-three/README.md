# 🍬 消消乐

经典三消游戏，交换相邻水果，三个相同连成一线即可消除得分。

## 玩法

- 点击一个水果选中，再点击相邻的水果交换位置。
- 交换后若有三个及以上相同水果连成横线或竖线，就会消除并得分，上方水果下落、顶部补充新的。
- 一次消除引发连续多轮消除时会有「连击 xN」加成，连击越高得分越多。
- 30 步内累计达到 1200 分即过关；步数用完未达标则挑战失败。
- 「🔄 重新挑战」重开一局；若棋盘没有可消除的交换会自动洗牌。

## 运行

打开 [index.html](index.html) 即可，或在入口页点击「消消乐」图标。纯前端，无需联网。已接入公共做题模块，游玩中会定时弹出题目。
