# ⬡ 六边形2048

还原微信小游戏「新2048 / 数字联盟爱消除」款型的六边形数字合成游戏。把数字块放进蜂窝棋盘，三个及以上相同数字连成一片就合成一个 4 倍大的数字，可连锁，考验布局规划。

## 玩法

有两种放置方式，可灵活搭配：

- **放置新数字**：底部「下一组」会显示 6 个数字块，**点一个选中**，再点棋盘上的**空格**放进去。
- **移动已有块**（补充玩法）：点棋盘上**已有数字的块**选中它（金色高亮），再点另一个**空格**，它会沿着**空格连成的路线**滑过去（路线被其他数字挡住则走不通，会给出提示）。把几块相同的数字搬到一起凑成 3 连即可合成——这样能主动布局、制造连锁。再点选中的块本身可取消；点别的块可改选。
  - **每个块只能移动一次**：移动过的块会变暗淡并打上「✓」标记，不能再被移动（点击会提示）；但**合成产生的新块会重新获得一次移动机会**。
- 当 **3 个及以上相同数字**通过六边形的六个方向连成一片时，自动合并成一个 **4 倍大**的数字（`1→4、2→8、4→16、8→32 …`），并在原地继续检查连锁合并。
- **得分** = 合成后的数字 × 连锁层数 × 参与合成的块数：合得越多、连锁越深、数字越大，得分越高（合并时有 `+N 分` 飘字反馈）。
- 数字按 4 倍合成递增：`1 → 4 → 16 → 64 → …`、`2 → 8 → 32 → 128 → …`（也可能直接放入 4、8 等），每种数字有专属颜色。
- 棋盘被填满且无法再放置/移动时本局结束；系统会记录最高分（存在本机）。

## 道具

- 🔄 **换一组**：重新随机「下一组」的数字（每局 5 次）。
- 🔨 **锤子**：点一下锤子再点棋盘上的某个数字，把它敲掉腾出空格（每局 3 次）。

## 动画效果

- **飞入放置**：点空格后，数字球从预览队列沿弧线飞到目标六边形，落点带涟漪与果冻弹出，飞行期间锁定操作避免误触。
- **沿路滑行**：移动已有块时，块会沿空白路径逐格滑到目标（果冻六边形保持造型），落地带涟漪。
- **合并汇聚**：合并时同组其他数字块向锚点吸附聚拢，锚点闪光后变成 4 倍数字并弹出得分飘字，连锁合并逐个播放。

**节奏优化**：所有动画时长集中在脚本顶部的 `ANIM` 配置对象，并同步到一组 CSS 变量（`--a-*`）作单一数据源，调整一处即可整体改变节奏。相对初版整体提速约 30%–40%（飞入 420→280ms、滑行每段 120→75ms、合并吸附 310→215ms、连锁间隔 200→120ms、飘分 900→620ms 等），落子与连锁更跟手、不再拖沓。性能上合并汇聚改为「先批量读取所有块的屏幕坐标，再批量写入样式」，消除读写交替导致的强制同步布局（layout thrashing）；飞入球与滑行块用 `will-change` 走 GPU 合成层。

## 操作说明

- 全部支持触摸：点选数字、点格放置、点按钮用道具。
- 返回值：左上角 🏠 或控制条最左「← 主页」。
- 已接入公共做题模块，游玩中会定时弹出题目，答题时游戏暂停。

## 运行

打开 [index.html](index.html) 即可，或在入口页点击「六边形2048」图标。纯前端，无需联网。
