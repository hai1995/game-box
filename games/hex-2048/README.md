# ⬡ 六边形2048

还原微信小游戏「新2048 / 数字联盟爱消除」款型的六边形数字合成游戏。把数字块放进蜂窝棋盘，三个及以上相同数字连成一片就合并翻倍，可连锁，考验布局规划。

## 玩法

有两种放置方式，可灵活搭配：

- **放置新数字**：底部「下一组」会显示 6 个数字块，**点一个选中**，再点棋盘上的**空格**放进去。
- **移动已有块**（补充玩法）：点棋盘上**已有数字的块**选中它（金色高亮），再点另一个**空格**，它会沿着**空格连成的路线**滑过去（路线被其他数字挡住则走不通，会给出提示）。把几块相同的数字搬到一起凑成 3 连即可合并——这样能主动布局、制造连锁。再点选中的块本身可取消；点别的块可改选。
- 当 **3 个及以上相同数字**通过六边形的六个方向连成一片时，自动合并成一个**翻倍**的数字，并在原地继续检查连锁合并。
- 合并得到的新数字越大，得分越高（每次合并加上新数字的值）。
- 数字从 1 起递增：`1 → 2 → 4 → 8 → 16 → 32 → 64 → 128 → … → 2048`，每种数字有专属颜色。
- 棋盘被填满且无法再合并时本局结束；系统会记录最高分（存在本机）。

## 道具

- 🔄 **换一组**：重新随机「下一组」的数字（每局 5 次）。
- 🔨 **锤子**：点一下锤子再点棋盘上的某个数字，把它敲掉腾出空格（每局 3 次）。

## 动画效果

- **飞入放置**：点空格后，数字球从预览队列沿弧线飞到目标六边形，落点带涟漪与果冻弹出，飞行期间锁定操作避免误触。
- **沿路滑行**：移动已有块时，块会沿空白路径逐格滑到目标（果冻六边形保持造型），落地带涟漪。
- **合并汇聚**：合并时同组其他数字块向锚点吸附聚拢，锚点闪光后翻倍，连锁合并逐个播放。

## 操作说明

- 全部支持触摸：点选数字、点格放置、点按钮用道具。
- 返回值：左上角 🏠 或控制条最左「← 主页」。
- 已接入公共做题模块，游玩中会定时弹出题目，答题时游戏暂停。

## 运行

打开 [index.html](index.html) 即可，或在入口页点击「六边形2048」图标。纯前端，无需联网。
