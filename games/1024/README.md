# 🔢 1024 数字合并

经典数字合并游戏，滑动方块让相同数字碰撞合并，目标是合出 1024。

## 玩法

- 手指在棋盘上滑动，或点击方向按钮 / 按键盘方向键（↑↓←→ / WASD）移动所有方块。
- 两个相同数字碰到一起会合并成它们的和（2+2=4、4+4=8……）。
- 每次有效移动会在空白处随机出现一个新的 2 或 4。
- 合出 1024 即「毕业」，可以选择继续挑战更大的数字；棋盘填满且无法合并时游戏结束。
- 顶栏显示当前得分与最高分（最高分保存在本机）。

## 运行

打开 [index.html](index.html) 即可，或在入口页点击「1024」图标。纯前端，无需联网。已接入公共做题模块，游玩中会定时弹出题目。
