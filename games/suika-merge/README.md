# 🍉 合成大西瓜

风靡全网的合成类休闲游戏，规则简单、老少皆宜。投下水果，相同的碰到一起就会合成更大的，一路合成到大西瓜！

## 玩法

- 移动鼠标或手指瞄准（顶部有虚线辅助），点击/松手投下当前水果。
- 两个**相同水果**相撞会合成下一个更大的水果：樱桃 → 橘子 → 柠檬 → 青提 → 苹果 → 火龙果 → 西瓜。
- 每次合成得分随等级递增；泡泡堆到顶部危险线就结束。
- 带简单的重力和碰撞物理效果，合成时有粒子与音效反馈。

## 存档

最高分通过公共存档 [`save.js`](../../save.js) 保存在本机，刷新后保留，升级不丢记录。支持音效开关与定时弹题（答对加分）。

## 运行

打开 [index.html](index.html) 即可，或在入口页点击「合成大西瓜」图标。纯前端，无需联网。
