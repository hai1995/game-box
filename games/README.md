# 游戏目录

所有游戏都放在本目录下，**每个游戏对应一个独立的子文件夹**。

## 添加新游戏

1. 新建子文件夹，命名建议使用英文或拼音，例如 `tetris/`、`guoguo/`，避免空格和特殊字符；
2. 将游戏文件全部放入该文件夹，不要散落在 `games/` 根目录；
3. 在该文件夹内创建 `README.md`，推荐模板如下：

```markdown
# 游戏名称

- **类型**：益智 / 动作 / 教育 / 休闲 / 其他
- **适合年龄**：如 5 岁以上
- **玩法简介**：一两句话说明怎么玩
- **运行方式**：如「用浏览器打开 index.html」或「安装 xx.apk」
```

4. 如果有封面图或截图，可放在游戏文件夹内并命名为 `cover.png`，方便统一展示。

## 进度存档（刷新后继续玩）

游戏盒子提供公共存档模块 [`save.js`](../save.js)，各游戏引入后即可把进度存到本机，刷新页面自动恢复，不必从头再来：

```html
<script src="../../save.js"></script>
```
```js
GameSave.save(key, data);          // 保存任意可 JSON 序列化对象
var s = GameSave.load(key, null);  // 读取（无档/损坏返回默认值）
GameSave.clear(key);               // 清档（通常「重新开始」时调用）
```

- **棋盘 / 解谜类**（1024、六边形2048、消消乐、连连看、五子棋、华容道、贪吃蛇、走迷宫、记忆翻牌等）：保存完整棋盘局面与分数、道具，刷新后原样接着玩。
- **关卡制**（箭头消除、找不同、打砖块、黄金矿工、小英雄等）：保存已达关卡与分数，刷新后从当前关继续。
- **实时街机类**（恐龙快跑、太空大战、赛车、打地鼠、算术泡泡、3D 飞行、小火车等）：一局本来就独立，保存最高分 / 最高波次等里程碑记录，刷新不丢成绩。

存档统一带 `gb_save_v1_` 前缀，读写都有异常保护（隐私模式、配额满也不影响游戏）；「重新开始 / 再玩一次」会清除对应进度。

├── gomoku/          # 五子棋
├── link-game/       # 连连看
├── match-three/     # 消消乐
├── snake/           # 贪吃蛇
