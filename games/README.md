# 游戏目录

所有游戏都放在本目录下，**每个游戏对应一个独立的子文件夹**。

## 添加新游戏

1. 新建子文件夹，命名建议使用英文或拼音，例如 `tetris/`、`guoguo/`，避免空格和特殊字符；
2. 将游戏文件全部放入该文件夹，不要散落在 `games/` 根目录；
3. 在该文件夹内创建 `README.md`，推荐模板如下：

```markdown
# 游戏名称

- **类型**：益智 / 动作 / 教育 / 休闲 / 其他
- **适合年龄**：如 5 岁以上
- **玩法简介**：一两句话说明怎么玩
- **运行方式**：如「用浏览器打开 index.html」或「安装 xx.apk」
```

4. 如果有封面图或截图，可放在游戏文件夹内并命名为 `cover.png`，方便统一展示。

## 进度存档（刷新后继续玩）

游戏盒子提供公共存档模块 [`save.js`](../save.js)，各游戏引入后即可把进度存到本机，刷新页面自动恢复，不必从头再来：

```html
<script src="../../save.js"></script>
```
```js
GameSave.save(key, data);          // 保存任意可 JSON 序列化对象
var s = GameSave.load(key, null);  // 读取（无档/损坏返回默认值）
GameSave.clear(key);               // 清档（通常「重新开始」时调用）
```

- **棋盘 / 解谜类**（1024、六边形2048、六边形2048 V2、消消乐、连连看、五子棋、华容道、贪吃蛇、走迷宫、记忆翻牌等）：保存完整棋盘局面与分数、道具，刷新后原样接着玩。
- **关卡制**（箭头消除、箭头消除高阶版、找不同、打砖块、黄金矿工、小英雄等）：保存已达关卡与分数，刷新后从当前关继续。
- **实时街机类**（恐龙快跑、太空大战、赛车、打地鼠、水果切切乐、算术泡泡、3D 飞行、小火车等）：一局本来就独立，保存最高分 / 最高波次等里程碑记录，刷新不丢成绩。

存档统一带 `gb_save_v1_` 前缀，读写都有异常保护（隐私模式、配额满也不影响游戏）；「重新开始 / 再玩一次」会清除对应进度。

### 升级不丢记录（重要）

记录存储遵循「尽可能保留玩家以往记录」原则，版本升级 / 玩法调整不会清零已有成绩：

- **公共存档模块** `save.js` 内置历史前缀回退与迁移机制：升级时若更换前缀，只需把旧前缀登记到 `LEGACY_PREFIXES`，`load` 会自动回退读取旧档并迁移到新前缀，旧键保留作双保险——绝不再靠「改版本号令旧存档失效」的方式清空记录。
- **历史最高成绩独立持久化**：街机类（恐龙快跑、赛车、太空大战、打地鼠、算术泡泡、3D 飞行、打砖块、六边形2048 系列等）的最高分 / 波次单独存 key，读档取历史最大值，重开、切关、结构变化时都不会被低分覆盖。
- **关卡进度设「历史最高关」**：走迷宫、找不同等额外保存 `maxLevel`，即使存档结构升级失效，也回到已达最高关而非第 1 关；找不同在通过当关瞬间即固化下一关进度。
- **版本迁移**：六边形2048 V2 首次进入会继承原版（V1）历史最高分，换版本不丢成绩。
- **结构容错**：读档按字段宽松恢复并保留可用字段，不会因个别字段缺失 / 类型变化就整体重置成绩。
- **棋盘尽力恢复**：1024、贪吃蛇等棋盘游戏升级 / 存档格式变化时，不再整盘丢弃重建——1024 兼容二维与旧扁平数组格式、逐格恢复有效数字并保留当前局分数；贪吃蛇过滤坏点后恢复有效蛇身与食物。即使无法 100% 还原棋盘，也保住尽可能多的局面与成绩，成就（最高分）始终独立保留、绝不清零。

├── hex-2048-v2/     # 六边形2048 V2 随机风暴（只显示当前块/无移动/随机增炸块）

├── link-game/       # 连连看
├── match-three/     # 消消乐

├── breakout/        # 打砖块
├── slide-puzzle/    # 数字华容道
├── find-difference/ # 火眼金睛找不同

│   ├── index.html
│   ├── level-gen.js # 1001 关起按关号实时生成（浏览器端）

│   ├── README.md
│   └── ...
└── ...
