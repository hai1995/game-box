# 💅 美甲设计

一款治愈系的美甲 DIY 小游戏，适合喜欢美妆的女生在碎片时间放松。给双手十个指甲挑选颜色与花样，设计属于自己的专属美甲。

## 玩法

- **选颜色**：从 20 种优雅甲油色中挑选喜欢的颜色（豆沙、酒红、裸粉、雾霾蓝、香芋紫等）。
- **选花样**：纯色、法式、波点、条纹、爱心、渐变、亮片、碎花共 8 种。
- **点指甲应用**：选中颜色和花样后，点击画面中的任意指甲即可涂抹；双手各 5 个指甲。
- **灵感随机**：一键生成随机配色方案；**一键卸甲**清空重来。
- **完成作品**：根据涂满数量、颜色种类、花样种类和双手呼应度计算「魅力值」（满分 100）。

## 存档

最佳魅力值与作品数通过公共存档 [`save.js`](../../save.js) 保存在本机，刷新后保留；当前设计中的配色也会保存，升级不丢记录。支持音效开关与定时弹题（答对有提示音）。

## 运行

打开 [index.html](index.html) 即可，或在入口页点击「美甲设计」图标。纯前端，无需联网。
