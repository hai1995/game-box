# 🧁 甜品烘培屋

一款甜蜜的甜品 DIY 小游戏，适合喜欢烘培与甜点的女生。亲手搭配蛋糕胚、奶油、水果、装饰和餐盘，出品一个专属小蛋糕。

## 玩法

- 5 个装饰维度标签：**蛋糕胚 / 奶油 / 水果 / 装饰 / 餐盘**，点标签切换，每类多种选项。
- Canvas 手绘蛋糕，奶油滴边、水果切片、蜡烛糖珠等细节随选择实时变化。
- **随机甜品**：一键生成随机组合；**清空装饰**重来。
- **完成出品**：根据水果/装饰丰富度与奶油/蛋糕的色系协调度计算「甜品分」（满分 100）。

## 存档

最佳甜品分、作品数与当前搭配通过公共存档 [`save.js`](../../save.js) 保存在本机，刷新后保留，升级不丢记录。支持音效开关与定时弹题。

## 运行

打开 [index.html](index.html) 即可，或在入口页点击「甜品烘培屋」图标。纯前端，无需联网。
