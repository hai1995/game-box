# 🍉 水果切切乐

专为低龄小朋友（约 4～7 岁）设计的切水果小游戏：用手指划过飞起来的卡通水果，把它们切成两半，果汁四溅、还有连击加分！画面鲜艳、无需识字、点一下就能玩，特别适合小男孩锻炼手眼协调。

- **类型**：休闲 / 动作（切水果）
- **适合年龄**：4～7 岁（6 岁小男孩推荐）
- **玩法简介**：按住手指划过水果即可切开得分；连续切有连击奖励，切中炸弹会扣分并抖动提示，但不结束游戏。一局 75 秒，时间到结算成绩。
- **运行方式**：用浏览器打开 [index.html](index.html)，或在入口页点击「水果切切乐」图标。纯前端，无需联网。

## 玩法

- 🍎 **切水果**：手指（或鼠标）划过水果，沿刀痕切成两半，每切一个得分。
- 🔥 **连击**：短时间内连续切，连击数越高每次得分越多，还会有「连切 N！」的鼓励提示。
- 💣 **躲炸弹**：黑色炸弹切到会扣 5 分并屏幕抖动，但不会结束游戏，对小朋友很友好。
- 😊 **卡通水果**：苹果、橙子、西瓜、草莓、柠檬、猕猴桃、葡萄，全都带可爱笑脸。
- 🔊 **声音开关**：右上角可开关合成的切割/爆炸音效。
- ✏️ **边玩边学**：游戏进行中会定时弹出口算题，答对额外加分（可在界面作答）。
