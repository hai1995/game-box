# 🥷 忍者快跑

经典横版忍者跑酷小游戏：控制红围巾忍者在月夜里一路向前，跨过障碍、甩出手里剑打倒机器人和乌鸦、收集金币，速度越来越快。手绘卡通美术 + 和风夜景，操作只需两根手指（或键盘），男女通吃。

- **类型**：动作 / 跑酷 / 休闲
- **适合年龄**：5 岁以上
- **玩法简介**：忍者自动奔跑，轻点跳跃（可二段跳），点红色按钮扔手里剑消灭敌人，收集金币加分；撞到障碍或敌人扣一颗心，3 颗心用完结束。
- **运行方式**：用浏览器打开 [index.html](index.html)，或在入口页点击「忍者快跑」图标。纯前端，无需联网。

## 玩法

- 👆 **跳跃**：轻点屏幕 / 空格 / ↑，再点一次可二段跳，跨过石墩、木箱、竹桩。
- ✴️ **手里剑**：点右下角红色按钮 / J 键 / ↓，甩出旋转手里剑打倒前方的机器人和乌鸦，连续击倒有「连斩」加分。
- 🪙 **金币**：碰到金币串即可收集，每枚 +5 分。
- ❤️ **生命**：撞到障碍或敌人扣 1 颗心并短暂无敌闪烁，3 颗心用完本局结束。
- 🏁 **难度**：跑得越远速度越快，分数随距离持续增长。
- 🔊 右上角可开关合成音效。

## 美术与场景

月夜渐变天空、闪烁星星、红月、远山、宝塔与竹林多层视差滚动；忍者带飘动的红围巾和背后的武士刀，奔跑/跳跃/投掷均有动画，敌人被击倒有碎片粒子。
