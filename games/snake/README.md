# 🐍 贪吃蛇

经典贪吃蛇，在草地上吃苹果，越吃越长，看谁能长最长。

## 玩法

- 点击「开始游戏」后，小蛇会自动向前走。
- 手指在棋盘上滑动（或电脑按方向键）改变小蛇的行进方向（不能立刻掉头）。界面不显示虚拟方向键，纯触摸滑动操作。
- 吃到手绘苹果（果冻质感 SVG，来自公共 `icons.js`）得 1 分、身体变长，吃得越多速度会略微加快。
- 撞到墙壁或咬到自己的身体就结束，页面会显示本局得分与最高分（最高分保存在本机）。

## 运行

打开 [index.html](index.html) 即可，或在入口页点击「贪吃蛇」图标。纯前端，无需联网。已接入公共做题模块，弹题时游戏会暂停。
