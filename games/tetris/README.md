# 🧱 俄罗斯方块

永不过时的经典方块游戏，男女老少都能玩。旋转、移动、堆叠，把方块消成整行得分。

## 玩法

- 方块从上方落下，可用按钮或键盘控制：**◀ ▶** 左右移动、**⟳** 旋转、**▼** 加速下落、**⤓** 直接落下、**⏸** 暂停。
- 键盘：`← →` 移动、`↑` 旋转、`↓` 加速、`空格` 直接落下、`P` 暂停。手机上也支持在棋盘上左右滑动移动、下滑加速。
- 手机横竖屏自适应；半透明投影显示方块落点，方便瞄准。
- 每消去 1~4 行得 100/300/500/800 分，消 10 行升一级、下落变快，挑战更高分。

## 存档

最高分通过公共存档 [`save.js`](../../save.js) 保存在本机，刷新后保留，升级不丢记录。支持音效开关与定时弹题（答对加分）。

## 运行

打开 [index.html](index.html) 即可，或在入口页点击「俄罗斯方块」图标。纯前端，无需联网。
