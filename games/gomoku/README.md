# ⚫ 五子棋

经典五子棋，支持**对战电脑**和**双人对战**两种模式，默认与电脑对战，适合小朋友自己玩或和家长一起玩。19×19 大棋盘，游玩时间更长。

## 玩法

- 默认是「🤖 对战电脑」模式：小朋友执黑棋先走，电脑执白棋自动应对；谁先把同色五颗棋子连成一条直线（横、竖、斜）谁就获胜。
- **最近落子提示**：每次落子（玩家或电脑）后，该棋子四周会闪烁金色/红色光晕，方便看清刚下在哪，轮到谁一目了然。
- **电脑等级**：棋盘上方有「低 / 中 / 高」三档，可自由切换，**默认「低」**：
  - 低：偏重进攻、防守较弱、带随机性，适合新手练习，多练几次就能赢；
  - 中：进攻与防守兼顾，会封堵你的连线；
  - 高：攻防均衡并做一步预判，会尽量化解你的威胁，挑战性更高。
  - 切换等级会即时生效并保存；双人模式下自动隐藏该选项。
- 点击「🤖 对战电脑」按钮可切换成「👥 双人对战」模式，两人轮流落子。切换模式会重新开始一局。
- 顶栏显示当前该谁走、已下步数；电脑思考时会提示「⚪ 电脑思考中…」。
- 「↩️ 悔棋」在对战电脑模式下会一次退回两步（玩家和电脑各一步），双人模式退一步；「🔄 重新开始」清空棋盘。
- 棋盘会随屏幕自动缩放，手机 / iPad 上点按落子即可。

## 进度与升级

- 棋盘局面、走子、当前回合、模式与电脑等级均通过公共存档 [`save.js`](../../save.js) 存在本机，刷新后原样接着玩。
- 从旧版 15×15 棋盘升级到 19×19 时，旧棋盘会**居中嵌入**新棋盘并保留走子与设置，绝不清空玩家进度。

## 运行

打开 [index.html](index.html) 即可，或在入口页点击「五子棋」图标。纯前端，无需联网。已接入公共做题模块，游玩中会定时弹出题目（弹题时电脑会暂停落子）。
