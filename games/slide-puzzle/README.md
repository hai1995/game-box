# 🔢 数字华容道

经典 3×3 数字华容道（滑块拼图），锻炼观察力和逻辑思维。

## 玩法

- 棋盘上有 1～8 八个数字和一个空格。
- 只能点击空格上、下、左、右相邻的数字，把它挪进空位。
- 目标是把数字按 1、2、3 / 4、5、6 / 7、8、空格 的顺序排好；排好位置正确的数字会变成绿色。
- 顶栏显示已走步数和用时，排好后弹出成绩。
- 「🔀 重新打乱」生成一个新局面，「🔄 重新开始」也重开一局。每次打乱都从完成态倒着随机走，保证一定有解。

## 运行

打开 [index.html](index.html) 即可，或在入口页点击「数字华容道」图标。纯前端，无需联网。已接入公共做题模块，弹题时计时会暂停。
