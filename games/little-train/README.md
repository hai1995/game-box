# 🚂 小火车呜呜开

- **类型**：休闲 / 儿童向
- **适合年龄**：6 岁及以上
- **玩法简介**：一款 3D 透视视角的无限开火车小游戏，专门为小朋友设计。小火车自动向前行驶，沿途收集星星 ⭐、爱心 ❤️、气球 🎈 并计分；在画面上左右滑动即可切换三条轨道，开到对应轨道才能接到收集物。途中还会钻山洞、经历白天与黑夜，累计里程每 100 米有里程碑庆祝。
- **运行方式**：用浏览器直接打开 `index.html` 即可（纯前端单文件，无需联网、无需安装依赖）。第一次点击「开始开车」时会开启声音。

## ✨ 画面特色

- **写实风列车**：蒸汽机车 + 多节彩色车厢，车头带锅炉/驾驶室/烟囱/大灯/排障器与连杆动轮，朝向镜头的守车车尾有尾灯、黄黑警示纹、车门与车窗反光；车身、车顶、窗户均用渐变与高光塑造立体金属质感，辐条车轮随行进转动。
- **透视轨道**：三条轨道从地平线一直延伸到屏幕下方，枕木向前滚动，营造驶来的纵深感。
- **换轨跟手**：左右滑动切换轨道，车头与车厢快速依次跟随，转弯利落。

## 🎮 操作说明

| 操作 | 效果 |
| --- | --- |
| ▶ 开始开车 | 开始游戏并开启音效 |
| 点击某条轨道 | 火车自动移动到该轨道 |
| 左右滑动画面 | 按滑动方向切换相邻轨道 |
| 点击天空 | 鸣笛 |
| 🚂 鸣笛 | 圆润的汽笛声 + 喷烟 |
| 🔔 叮咚 | 清脆铃铛声 |
| 💨 喷气 | 蒸汽嘶嘶声 |
| ⚡ 加速 | 提速冲刺：镜头推近、火车前冲、速度线爆发与冲击光效；再按一次恢复常速 |
| 🎉 烟花 | 放彩色烟花 |

技能按钮分列屏幕中上部左右两侧各一竖列，每列 5 个，共 10 个，不遮挡下方火车与轨道，随手即可触发。

## 🔊 音效

所有音效均由 Web Audio API 实时合成，无需任何音频文件：汽笛、铃铛、喷气、加速冲刺、烟花、收集奖励、钻洞呼啸、里程碑以及持续的引擎声。
