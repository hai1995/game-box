# 👀 火眼金睛找不同

考验眼力的小游戏：一堆相同的图案里藏着一个不一样的，用最短时间把它找出来。16 种图案均为手绘果冻质感 SVG 图标（来自公共 `icons.js`），风格统一。

## 玩法

- 点击「开始游戏」，在表情网格里找出那个与其他不同的表情并点击它。
- 找对就得分解锁下一关；关卡越高，网格越大（从 3×3 到 6×6），时间也略有挑战。
- 点错不会扣分，那个格子会抖一下，继续找就行。
- 时间到还没找出会显示答案和当前得分，可重新开始。
- 顶栏显示当前关卡、得分和剩余时间。

## 运行

打开 [index.html](index.html) 即可，或在入口页点击「火眼金睛」图标。纯前端，无需联网。已接入公共做题模块，弹题时倒计时会暂停。
