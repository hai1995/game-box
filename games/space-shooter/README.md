# 🚀 太空大战

竖版飞行射击小游戏。驾驶飞船消灭入侵的外星飞碟和陨石，保护地球。

## 玩法

- 手指在屏幕上左右拖动移动飞船（也支持 ← → / A D 键）。
- 子弹自动发射，击落目标得分：普通飞碟 +12、强化飞碟 +20、陨石 +8。
- 被敌机/敌弹撞到扣 1 条命（共 3 条），受击后短暂无敌闪烁。
- 每 14 秒进入下一波（共 12 波），敌机速度、数量、强化比例递增。

## 实现

- 单文件 `index.html`，内联 CSS/JS，Canvas 逐帧渲染。
- 飞船、飞碟、陨石、子弹、尾焰均为果冻质感手绘，深空渐变背景 + 滚动星空。
- 敌机会左右反弹移动、飞碟会周期性开火；碰撞为 AABB 近似判定。
- 移动端：`pointermove`/`touchmove` 拖动控制，`touch-action:none`，安全区适配。
- 已接入公共主题 `theme.css`、图标库 `icons.js`、做题模块 `quiz.js`（弹题时暂停、答对 +10 分）。
- 返回主页：左上角 🏠。
