# ➡️ 箭头消除 · 无限关卡

参考《解压1000关》的「箭头消除」解谜游戏。棋盘上布满带方向的箭头，点箭头让它沿朝向飞出棋盘，腾出通道——被别的箭头挡住就扣一次机会，清空全部箭头即通关。前 1000 关预生成、之后**无限关卡**持续生成，难度平滑递进，既能给小朋友入门，也能挑战成年人。

## 玩法

- **点箭头**：从箭头末端沿它指的方向射向棋盘边缘；若射线上没有**其他**箭头挡路，这条箭头就像小蛇一样**顺着自身轨迹游出棋盘**——箭头尖先钻出边界，身体逐节沿原路径跟进、带拖尾残影与速度线，最后尾巴离开，整条消除。
- **被挡住**：射线上有别的箭头时操作失败，扣 1 次机会（每关 3 次），并闪红提示。挡路的箭头要先消除掉。
- **通关**：清空本关所有箭头即可进入下一关；机会扣完或倒计时归零则失败，可重试本关。
- **依赖嵌套**：箭头会互相挡路，需要找出正确的消除顺序，层层解开。
- **缩放/平移盘面**：高关卡棋盘大、格子小，可**双指捏合**放大缩小、**单指拖动**平移查看边缘；电脑上用**鼠标滚轮**缩放、按住拖动平移。缩放/拖动不会误触发消除（只有轻点才消除），点底部「适应屏幕」或换关即复位到全貌。缩放范围 100%–500%。

## 计时与加时

- 倒计时**从点击第一个箭头才开始**，进关不会白白扣时。
- 基础时长按难度段递增：入门/进阶 10:00、迷宫 12:00、深迷宫A 14:00、深迷宫B 16:00、终极 18:00、大师 20:00、宗师/无尽 21:00。
- **连消奖励**：连续正确消除 5 个箭头 +5 秒，最多累计 +30 秒；被挡会中断连击。
- 最后 30 秒倒计时变红提醒（不使用声音打断）。
- 游玩中定时弹出公共题库的题目，答题时倒计时暂停。

**难度强化**：提高各段塞满率目标、后期折弯预算升到 6 折、降低贴边末端比例让更多射线深入棋盘彼此遮挡；拒绝采样在达标候选中优选「初始可消箭头少、依赖层数多」的布局，关卡更嵌套难解。前 1000 关全部达标（0 降级）、全部通过可解性校验。

## 关卡生成（算法）

关卡统一用**反向构造法**生成，核心不变式：从空棋盘开始，按「合法消除顺序的逆序」依次放入箭头，只要求新箭头射线不碰已放入的箭头，后续箭头即使挡住它也会先被消除，因此必然可解。末端部分贴边朝外、部分深入棋盘形成长射线，路径受折弯预算约束，靠互相遮挡制造嵌套依赖；再用**求解器 + 拒绝采样**复核可解、塞满率达标，并在达标候选中按「依赖层数多、初始可消少」挑最难的。

**空腔填补**：反向构造到后期，空腔里的格子几乎都被四周箭头的射线挡住，无法再当新箭头末端，高关卡中央会留下明显的大块空白。修复办法是把补充箭头放到消除序列最前（数组头部、最后消除）——它们 id 最小必能最后飞出，只要格子不落在其它箭头的射线上就不会挡路。于是反复在「不在任何射线上」的安全格里补箭头并头插，棋盘填充率从约 64% 提升到 **69.6%–91%（无尽段稳定约 79%）**，空白变成零散小缝；填补后再跑一次求解器复核，失败自动回退，绝不影响可解性。

- **前 1000 关（预生成）**：[`tools/gen-levels.js`](../../tools/gen-levels.js) 离线生成，数据存为 `levels/l001.js`…`l010.js`，每块 100 关紧凑编码，进入对应关卡时才加载，不在手机上实时计算。[`tools/verify-levels.js`](../../tools/verify-levels.js) 可全量校验可解性、路径无重叠、限时与塞满率。
- **1001 关起（运行时生成）**：[`level-gen.js`](level-gen.js) 把同一套算法放到浏览器端，**关号即随机种子**——同一关每次生成完全一致（可重试、可分享关号）。单关生成约 30–170ms（大盘面按规模递减尝试次数来提速，有 loading 遮罩），配「内存 + localStorage」轻量缓存（保留最近 120 关），不卡顿。生成后同样跑求解器复核，绝不出现死局。棋盘与箭头数随关号对数持续增长（28×37/60 → 76×102/280+），难度另靠折弯/嵌套深度爬升。缓存 key 为 v4（升级盘面曲线后自动作废旧缓存）。
