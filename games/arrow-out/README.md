# ➡️ 箭头消除 1000 关

参考《解压1000关》的「箭头消除」解谜游戏。棋盘上布满带方向的箭头，点箭头让它沿朝向飞出棋盘，腾出通道——被别的箭头挡住就扣一次机会，清空全部箭头即通关。共 1000 关，难度平滑递进，锻炼观察与顺序推理。

## 玩法

- **点箭头**：从箭头末端沿它指的方向射向棋盘边缘；若射线上没有**其他**箭头挡路，这条箭头就飞出消除。
- **被挡住**：射线上有别的箭头时操作失败，扣 1 次机会（每关 3 次），并闪红提示。挡路的箭头要先消除掉。
- **通关**：清空本关所有箭头即可进入下一关；机会扣完或倒计时归零则失败，可重试本关。
- **依赖嵌套**：箭头会互相挡路，需要找出正确的消除顺序，层层解开。

## 计时与加时

- 倒计时**从点击第一个箭头才开始**，进关不会白白扣时。
- 基础时长按难度段递增：入门/进阶 10:00、迷宫 12:00、深迷宫A 14:00、深迷宫B 16:00、终极 18:00。
- **连消奖励**：连续正确消除 5 个箭头 +5 秒，最多累计 +30 秒；被挡会中断连击。
- 最后 30 秒倒计时变红提醒（不使用声音打断）。
- 游玩中定时弹出公共题库的题目，答题时倒计时暂停。

## 关卡生成（算法）

关卡由 [`tools/gen-levels.js`](../../tools/gen-levels.js) **反向构造法**预生成，运行时按需加载，不在手机上实时计算：

1. 从空棋盘开始，按「合法消除顺序的逆序」依次放入箭头：只要求新箭头射线不碰已放入的箭头，后续箭头即使挡住它也会先被消除，因此必然可解。
2. 末端优先贴边朝外、路径直线深入并受折弯预算约束，提升塞满率与嵌套深度。
3. **求解器 + 拒绝采样**：每关换种子多次生成，跑求解器验证可解、塞满率达标才采用；放不下时降级补足并告警。
4. 数据存为 `levels/l001.js`…`l010.js`，每块 100 关紧凑编码，进入对应关卡时才加载。
5. [`tools/verify-levels.js`](../../tools/verify-levels.js) 可全量校验 1000 关的可解性、路径无重叠、限时与塞满率。

打开 [index.html](index.html)，或在入口页点击「箭头消除」图标。纯前端，无需联网。进度（当前关卡）保存在本机。
