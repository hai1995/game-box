# 🫧 泡泡龙

经典的泡泡射击消除游戏，操作简单、男女老少都能玩。射出彩色泡泡，三个以上同色连在一起即可消除。

## 玩法

- 移动鼠标或手指瞄准（带瞄准虚线），点击/松手发射泡泡。
- **3 个及以上同色泡泡相连**即消除得分；失去支撑的泡泡会整片掉落，额外加分。
- 清空所有泡泡即通关；泡泡堆到底部危险线则游戏结束。
- 射击彩泡颜色显示在「下一颗」与提示文字中，方便规划落点。

## 存档

最高分通过公共存档 [`save.js`](../../save.js) 保存在本机，刷新后保留，升级不丢记录。支持音效开关与定时弹题（答对加分）。

## 运行

打开 [index.html](index.html) 即可，或在入口页点击「泡泡龙」图标。纯前端，无需联网。
