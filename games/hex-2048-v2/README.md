# ⬡ 六边形2048 V2 · 随机风暴

在经典《六边形2048》基础上重构的进阶版本：**更纯粹、更看运气**。取消后续方块预告与自由移动，只给你当下这一块；每次落子后棋盘都会"自己动"——随机增块或炸块，局势瞬息万变。

## 与原版的区别

| 机制 | 原版 | V2 随机风暴 |
| --- | --- | --- |
| 方块预览 | 显示后续 6 块，可任意挑 | **只显示当前 1 块**，没有后续提示 |
| 自由移动 | 可点已有块沿空格滑行（每块一次） | **取消移动**，只能往空格放当前块 |
| 落子后 | 棋盘不变 | **每次落子随机触发**：增块 45% / 炸块 35% / 不随机 20% |
| 道具 | 换一组、锤子 | 换一块、锤子（均保留） |
| 美术动画 | 飞入/滑行/合并 | 保留并新增**爆炸火球**、冲击波、碎片飞散、增块闪光、事件横幅 |

## 玩法

- **放块**：点控制条"当前块"（只有 1 个），再点棋盘上的**空格**放下。V2 没有后续预告，落子全靠当下决断。
- **不能移动**：已有块无法再被选中移动（点它会提示）；只能靠落子位置和随机增块去凑连。
- **合并**：当 **3 个及以上相同数字**沿六边形六向连成一片，自动合成 **4 倍大**数字（`1→4、2→8、4→16 …`），并可继续连锁。
- **随机风暴**（核心）：每次落子完成、合并连锁彻底结束后，按概率触发一次：
  - ✨ **增块 45%**：在随机空格生成一个随机数字（带金色闪光 + `+N` 飘字），若恰好凑成 3 连会自动合并；
  - 💥 **炸块 35%**：随机炸掉一个已有数字（火球爆炸 + 冲击环 + 碎片飞散动画）；
  - 😌 **不随机 20%**：风平浪静，棋盘不变。
- **得分** = 合成后的数字 × 连锁层数 × 参与块数；随机增块引发的合并同样计分。
- 棋盘被填满无法再放置时本局结束；最高分存在本机（独立 key `hex2048v2best`，不与原版混淆）。

## 道具

- 🔄 **换一块**：重新随机当前块（每局 5 次）。
- 🔨 **锤子**：点锤子再点某个数字，主动敲掉它腾出空格（每局 3 次，带爆炸反馈）。

## 动画效果

- **飞入放置**：数字块从当前块位置沿弧线飞到目标格，落点带涟漪。
- **合并汇聚**：同组块向锚点吸附，闪光后变 4 倍数字并弹出得分飘字，连锁逐个播放。
- **💥 爆炸**（新增）：炸块/锤击时爆出火球、扩散冲击环与四散碎片。
- **✨ 增块**（新增）：新块亮起金色高光并上浮 `+N`。
- **事件横幅**（新增）：每次随机事件在画面上方弹出彩色提示条。

**节奏**：所有动画时长集中在脚本顶部 `ANIM` 对象，并同步到 CSS 变量 `--a-*`，一处修改即可整体调整。

## 操作说明

- 全部支持触摸：点块、点格放块、点按钮用道具。
- 左上角 🏠 返回主页。
- 已接入公共做题模块，答题时游戏暂停。

## 运行

直接打开 [index.html](index.html) 即可，纯前端、无需联网。也可在入口页点击带 **V2** 角标的「六边形2048」图标进入。
