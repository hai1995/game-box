# 🔗 连连看

经典连连看，找出相同图案并用不超过两次拐弯的直线连起来消除。12 种水果全部为手绘果冻质感 SVG 图标（来自公共 `icons.js`），风格统一、小尺寸易分辨。

## 玩法

- 依次点击两张相同的图案，只要连接路径的拐弯不超过两次、且中间没有其它图案挡住，就能消除。
- 棋盘外圈可以绕行，方便连边缘的图案。
- 10 分钟倒计时（时间更充裕），把所有 24 对水果消完即通关；时间到还有剩余则挑战失败。
- 「💡 提示」会高亮一对当前可以消除的图案；「🔀 重排」打乱剩余图案；「🔄 重来」重开一局。
- 如果没有任何可消除的配对，棋盘会自动重排，保证一直有解。

## 运行

打开 [index.html](index.html) 即可，或在入口页点击「连连看」图标。纯前端，无需联网。已接入公共做题模块，弹题时倒计时会自动暂停。
