# 👗 时尚换装

一款轻松的纸娃娃换装小游戏，适合喜欢穿搭的女生。自由搭配发型、上衣、下装、鞋子和配饰，打造心目中的今日造型。

## 玩法

- 头顶 5 个分类标签：**发型 / 上衣 / 下装 / 鞋子 / 配饰**，点标签切换。
- 每类有多种选项（含颜色小圆点标识），点选即换装，Canvas 实时绘制人物。
- **随机一套**：一键生成随机穿搭寻找灵感。
- **给搭配打分**：根据色系统一度、配饰点睛、基础色百搭度计算「搭配分」（满分 100），并给出风格评语（暖色系 / 冷色系 / 简约中性色）。

## 存档

最佳搭配分、造型计数与当前穿搭通过公共存档 [`save.js`](../../save.js) 保存在本机，刷新后保留，升级不丢记录。支持音效开关与定时弹题。

## 运行

打开 [index.html](index.html) 即可，或在入口页点击「时尚换装」图标。纯前端，无需联网。
