# ✈️ 3D 飞行视角大冒险

- **类型**：3D 飞行 / 休闲 / 儿童向
- **适合年龄**：6 岁及以上
- **玩法简介**：一款 3D 第一人称飞行视角小游戏，专门为小朋友设计。黑色炫酷战机固定在屏幕中央，滑动或倾斜手机即可 360° 转向飞行，去接迎面飞来的星星 ⭐ 和各种水果 🍎🍊🍇🍌🍉 得分，避开乌云和闪电 ⚡。打开网页直接开玩，无需点开始，没有时间限制、不会结束。
- **运行方式**：用浏览器直接打开 `index.html` 即可（Three.js 3D 引擎 `three.min.js` 已随游戏放在同一文件夹，无需联网、无需安装依赖）。

## 🎮 操作说明

| 操作 | 效果 |
| --- | --- |
| 手指滑动 / 鼠标拖动 | 往哪滑就往哪飞：左右转向、上下抬头俯冲改变高度 |
| 方向键 / WASD（电脑） | 左转、右转、爬升、俯冲 |
| 📱 陀螺仪按钮（左上） | 开启后转动 / 倾斜手机即可控制方向（手机需授权传感器权限） |
| 🚀 导弹（或 J 键） | 朝前方发射导弹，击碎乌云 +2/+3、击败地面怪物 +5 |
| ⚡ 加速（或 B 键） | 喷筒爆发冲刺 3 秒 |
| 🛡️ 隐身（或空格键） | 短暂无敌穿过障碍物 |
| ❓ 帮助按钮（右上） | 查看玩法小卡片 |

> 导弹、加速、隐身三个技能都会消耗积分区分，积分不够时会提示"积分不够啦~"。

## ✨ 游戏特色

- 🛩️ 炫酷隐形战机：深黑金属机身、青色发光座舱、霓虹灯带呼吸闪烁、蓝色双喷口尾焰
- 🌟 丰富奖励物：星星 +1，苹果 +2、橙子 +2、葡萄 +5、香蕉 +2、西瓜 +4
- ⚡ 危险挑战：灰色乌云 -1 分、黑色闪电乌云 -2 分，用导弹或隐身应对
- 🌍 立体场景：可穿梭的城市、森林、跑道、地面怪物，配 360° 远山与云海，抬头爬升、低头俯冲有真实高度变化
- 📝 算术闯关：每 5 分钟弹出十以内加法题，做对 +5 并语音鼓励，做错 -1 直到做对
- 🔊 音效丰富：导弹发射轰鸣、收集叮咚、爆炸、语音鼓励等均由 Web Audio API 实时合成

## 📁 文件说明

- `index.html`：游戏主程序（HTML + CSS + JavaScript 全部内联）
- `three.min.js`：Three.js r128 3D 引擎（本地文件，无需联网加载）
