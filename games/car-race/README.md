# 🏎️ 疯狂赛车

竖版躲避竞速小游戏。左右拖动你的赛车，在车流中穿梭、捡金币，开得越远越厉害。

## 玩法

- 手指左右拖动移动赛车（也支持 ← → / A D 键），车身会随转向自然倾斜。
- 躲开迎面而来的车，撞车扣 1 条命（共 3 条），车速会略微下降，受击后短暂无敌。
- 捡到金币 +15 分；行驶距离持续累积分数。
- 车速随时间递增（上限 560 px/s），来车越来越密，三条路不会同时被堵死（保底留出通路）。

## 实现

- 单文件 `index.html`，内联 CSS/JS，Canvas 逐帧渲染。
- 赛车（己方红色 + 5 种来车配色）、金币、路面均为果冻质感手绘；草地/公路/车道虚线随速度滚动。
- 金币用椭圆压缩模拟旋转动画；来车带尾灯与朝向车灯区分方向。
- 移动端：`pointermove`/`touchmove` 拖动控制，`touch-action:none`，安全区适配。
- 已接入公共主题 `theme.css`、图标库 `icons.js`、做题模块 `quiz.js`（弹题时暂停、答对 +10 分）。
- 返回主页：左上角 🏠。
