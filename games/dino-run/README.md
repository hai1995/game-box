# 🦖 恐龙快跑

横版跑酷小游戏。帮小恐龙跳过仙人掌和飞鸟、收集恐龙蛋，跑得越远越厉害。

## 玩法

- 轻点屏幕 / 按空格 / 按 ↑ 让恐龙跳跃；按住不连点，落地后才能再跳。
- 躲避地面仙人掌和空中飞鸟，撞到扣 1 条命（共 3 条），受击后短暂无敌。
- 收集恐龙蛋 +5 分，跑得越远速度和分数越高（分数含距离累积）。
- 无终点，跑到 3 条命耗尽结束，可一键再跑。

## 难度

- 速度随存活时间持续增加（190 → 上限 520 px/s），障碍间距随速度缩短但保留可跳下限。
- 障碍类型随速度解锁：低速只有仙人掌，速度上来后出现高低两种飞鸟。

## 实现

- 单文件 `index.html`，内联 CSS/JS，Canvas 逐帧渲染（`requestAnimationFrame` + dt）。
- 恐龙、仙人掌、飞鸟、恐龙蛋全部为果冻质感手绘（渐变 + 左上高光 + 统一描边），与全站美术一致。
- 视差背景：滚动的云、远山、太阳光晕与地面纹理。
- 移动端：整屏 `pointerdown` 跳跃、`touch-action:none` 防误滚，安全区适配。
- 已接入公共主题 `theme.css`、图标库 `icons.js`、做题模块 `quiz.js`（弹题时暂停、答对 +10 分）。
- 返回主页：左上角 🏠。
