# ⛏️ 黄金矿工

经典挖矿小游戏。看准时机放下钩爪，抓金块和钻石、避开石头，限时达到目标分数即可过关。

## 玩法

- 钩爪在头顶左右摆动（**爪子固定朝下、不随绳子旋转**，更易对准），轻点屏幕 / 按空格放下钩爪。
- 抓到东西后自动收回，重量越大收得越慢；收回到顶计入分数。
- 价值：大金块 100、小金块 50、钻石 250、神秘袋 80~400 随机、石头仅 12（尽量别抓）。
- **抓中加时**：收到金块 +3s、大金块 +5s、钻石 +8s、神秘袋 +2s；石头不加时。抓得准就能越玩越久。
- **炸药道具 💣**：每关 3 个。当钩爪勾住物品时点右下角炸药按钮（或按 `X`/`B`），可把勾住的东西炸掉（不计分）并**立即快速收回钩爪**——误抓石头时用来止损、抢时间。按钮在勾住物品时才亮起。
- 限时内累计分数达到目标即过关，剩余时间额外奖励（每秒 +2 分）；未达标则失败重试。
- 关卡递进：物品数从 10 增到 18，石头比例随关卡上升，目标分数递增并封顶 1000，时间 90 秒起、最低 70 秒。

## 难度设计

- 每关保底放置多个大金块和钻石（第 3 关起再加一颗钻石），确保目标始终可达。
- 目标分数按「物品数 × 单件均值」估算并封顶，避免后期物品数封顶后目标无限上涨导致不可通关。

## 实现

- 单文件 `index.html`，内联 CSS/JS，Canvas 逐帧渲染。
- 矿工、滑轮、钩爪、金块、钻石、石头、钱袋均为果冻质感手绘；地下土层带纹理与碎石。
- 钩爪状态机：摆动 `swing` → 伸出 `extend`（命中或到底）→ 收回 `retract`（按重量调速）；炸药触发 `retractFast`（匀速快速收回、不计分）。
- 爪子绘制固定朝下（`drawClaw` 不再随 `hook.angle` 旋转）；被勾物品在收回途中悬挂显示，方便判断要不要炸。
- 移动端：`pointerdown` 放钩、`touch-action:none`，安全区适配；炸药按钮单独放开 `pointer-events` 以便点击。
- 已接入公共主题 `theme.css`、图标库 `icons.js`、做题模块 `quiz.js`（弹题时暂停、答对 +15 分）。
- 返回主页：左上角 🏠。
